## סקירה כללית

מערכת לניהול קריאות שירות בתחום הגראז'ים, שבה לקוח פותח קריאה באתר עם פרטי תקלה, רמת דחיפות ומיקום. המערכת מזהה את הטכנאי המתאים ביותר לפי מיקום GPS, התמחות וזמינות ביומן Google, ומשבצת אותו אוטומטית.

**עקרון מנחה ל-POC:** הקמה בעלות אפס באמצעות שירותי Google בלבד.

- **Google Sheets** = מסד הנתונים
- **Google Apps Script** = ה-Backend
- **Google Calendar** = לוח השיבוצים
- **Google Forms / אתר סטטי** = הממשק ללקוח
- **Looker Studio** = הדשבורד

---

## תפקידים במערכת

| תפקיד | פעולות עיקריות |
|-------|-----------------|
| **לקוח** | פותח קריאה, עוקב אחר סטטוס, מאשר סיום |
| **טכנאי** | מקבל שיבוצים, מעדכן סטטוס בשטח, מנווט ללקוח |
| **דיספצ'ר/מנהל** | רואה תמונת מצב, מתערב בשיבוץ ידני, מנהל לקוחות וטכנאים |
| **מנהל מערכת** | הגדרות, הרשאות, אזורי שירות |

---

## תהליך קריאת שירות (End-to-End)

1. לקוח ממלא טופס באתר: סוג תקלה, רמת דחיפות (רגיל/דחוף/חירום), מיקום (כתובת או GPS), פרטי רכב, תמונות
2. המערכת מסווגת את הקריאה ומחשבת זמן טיפול משוער
3. אלגוריתם השיבוץ בוחר טכנאי לפי קריטריונים
4. נוצר אירוע ב-Google Calendar של הטכנאי + התראת Push/SMS
5. הטכנאי מאשר/דוחה. אם דוחה – המערכת מציעה טכנאי חלופי
6. בשטח: עדכוני סטטוס (בדרך / הגעתי / בטיפול / הסתיים)
7. סגירת קריאה: חתימת לקוח, חשבונית, סקר שביעות רצון

## מודולים מרכזיים

- **ניהול לקוחות** – פרטים, היסטוריית קריאות, רכבים מקושרים, תיעוד תקשורת
- **ניהול קריאות** – סטטוסים, SLA לפי דחיפות, תיעוד עבודה, חלקי חילוף
- **ניהול טכנאים** – פרופיל, התמחויות (חשמל/מכונאות/פחחות), אזורי פעילות, שעות עבודה, זמינות בזמן אמת
- **מפה חיה** – תצוגת דיספצ'ר עם מיקום כל הטכנאים והקריאות הפתוחות
- **דוחות וביצועים** – זמן תגובה ממוצע, שביעות רצון, עומס לטכנאי, הכנסות

## ארכיטקטורת POC על תשתית Google

### שכבת קלט (לקוח)

Google Form או דף HTML פשוט (אפשר לארח חינם ב-GitHub Pages / Netlify) עם השדות:

- שם מלא
- טלפון
- סוג תקלה (רשימה נפתחת)
- רמת דחיפות
- כתובת + כפתור **"קבל מיקום נוכחי"** (Geolocation API של הדפדפן → lat/lng)
- פרטי רכב
- תמונות (אופציונלי)

### שכבת אחסון – Google Sheets

קובץ אחד עם חמישה גליונות:

#### גליון `Calls`
| עמודה | סוג | תיאור |
|--------|-----|--------|
| call_id | String | מזהה ייחודי |
| created_at | DateTime | תאריך פתיחה |
| customer_id | String | מזהה לקוח |
| issue_type | String | סוג תקלה |
| urgency | Enum | רגיל / דחוף / חירום |
| lat | Number | קו רוחב |
| lng | Number | קו אורך |
| address | String | כתובת מלאה |
| assigned_technician | String | מזהה טכנאי |
| status | Enum | חדש / משובץ / בדרך / בטיפול / הסתיים |
| eta | DateTime | זמן הגעה משוער |
| notes | String | הערות |

#### גליון `Technicians`
| עמודה | סוג | תיאור |
|--------|-----|--------|
| tech_id | String | מזהה |
| name | String | שם מלא |
| phone | String | טלפון |
| specialties | Array | התמחויות |
| service_area | String | אזור שירות |
| calendar_id | String | מזהה יומן Google |
| current_lat | Number | מיקום נוכחי |
| current_lng | Number | מיקום נוכחי |
| last_location_update | DateTime | עדכון מיקום אחרון |
| is_active | Boolean | פעיל/לא פעיל |
| rating | Number | דירוג ממוצע |

#### גליון `Customers`
פרטי לקוח, רכבים מקושרים, היסטוריה

#### גליון `Assignments_Log`
לוג של כל פעולות השיבוץ לצורך אנליטיקה ודיבוג

#### גליון `Settings`
SLA לפי דחיפות, רדיוס חיפוש, פרמטרים לאלגוריתם

### שכבת לוגיקה – Google Apps Script

ה-Backend החינמי. הפונקציות המרכזיות:

```javascript
doPost(e)              // מקבל קריאה חדשה מהטופס/אתר
assignTechnician(call) // אלגוריתם שיבוץ
createCalendarEvent()  // יוצר אירוע ביומן הטכנאי
updateStatus()         // API לעדכון סטטוס מהטכנאי
updateTechLocation()   // עדכון מיקום טכנאי
```

טריגר אוטומטי שרץ על שורה חדשה ב-Sheet ומפעיל את `assignTechnician`.

### שכבת הטכנאי

- כל טכנאי משתף את היומן שלו עם חשבון המערכת (הרשאת עריכה)
- **עדכון מיקום:** דף web פשוט שהטכנאי פותח בנייד, משתמש ב-Geolocation API ושולח lat/lng ל-Apps Script כל X דקות
- **חלופה:** כפתור "אני זמין עכשיו" שמעדכן ידנית
- **קבלת שיבוץ:** מקבל אירוע ביומן Google אוטומטית, עם כתובת ולינק ל-Waze

### שכבת הדיספצ'ר

- **Google Sheets** עצמו עם תצוגות מסוננות וצביעה לפי סטטוס (Conditional Formatting)
- **Looker Studio** (חינם) למפה חיה ודשבורד ניהולי

## אלגוריתם השיבוץ

### לוגיקה בסיסית

```
1. מצא טכנאים פעילים מתאימים להתמחות הנדרשת
2. עבור כל אחד:
   א. חשב מרחק אווירי (Haversine) מהקריאה
   ב. בדוק זמינות ביומן בשעה הקרובה (Calendar API)
   ג. בדוק עומס נוכחי (כמה קריאות פתוחות)
3. חשב ציון לכל טכנאי
4. בחר את בעל הציון הגבוה ביותר
5. צור אירוע ביומן שלו + עדכן ב-Sheet
6. אם הטכנאי דוחה תוך X דקות → עבור לבא בתור
```

### קריטריונים לניקוד

| קריטריון | משקל | הערה |
|-----------|------|------|
| מרחק נסיעה | גבוה | מרחק אווירי ב-POC, Maps API לדיוק |
| התמחות מתאימה | חובה | סינון, לא ניקוד |
| חלון זמן פנוי ביומן | חובה | סינון |
| עומס נוכחי | בינוני | למניעת הצפה |
| דחיפות מול SLA | גבוה | חירום עוקף תור רגיל |
| דירוג ביצועים | נמוך | טיי-ברייקר |

### למה מרחק אווירי ב-POC?

חישוב Haversine ב-Apps Script הוא מקומי ומהיר, ללא קריאות API. ל-Production מומלץ Google Maps Distance Matrix לקבלת זמן נסיעה אמיתי (חינם עד 28,000 קריאות בחודש).

## מגבלות וניצול מכסות חינמיות

| שירות | מגבלה חינמית | מספיק ל-POC? |
|-------|--------------|---------------|
| Google Sheets | 10M תאים לקובץ | בקלות |
| Apps Script | 6 דקות הרצה / 20K טריגרים ביום | כן, לעשרות קריאות ביום |
| Calendar API | 1M בקשות ביום | בשפע |
| Geolocation API (דפדפן) | חינם לחלוטין | כן |
| Maps Embed / Static | חינמי בעיקרו | כן |
| Looker Studio | חינם | כן |

### מגבלות שכדאי להכיר מראש

- **אין Real-time אמיתי** – Apps Script לא תומך ב-WebSockets. עדכוני מפה יהיו ב-polling (רענון כל דקה)
- **6 דקות זמן ריצה** – אם יש הרבה טכנאים, צריך לאופטם את החיפוש
- **אבטחה בסיסית** – Sheets כמסד נתונים זה לא Production. ל-POC זה בסדר, אבל לא לשים שם פרטי אשראי
- **GPS רציף בנייד** – דפדפן לא מאפשר tracking ברקע אם המסך כבוי. הפתרון: הטכנאי משאיר את הדף פתוח, או מעדכן ידנית "התחלתי משמרת"

## מסלול הקמה מומלץ

1. **הקמת קובץ Sheets** עם הגליונות והעמודות לפי הסכמה
2. **כתיבת Apps Script בסיסי** שכותב קריאה ל-Sheet
3. **בניית Google Form או דף HTML** פשוט שמזין נתונים
4. **חיבור ליומני Google** של הטכנאים + פונקציה שיוצרת אירוע
5. **כתיבת אלגוריתם השיבוץ** עם Haversine וקריאת Calendar API
6. **דף web לטכנאי** לעדכון מיקום וסטטוס
7. **דשבורד ב-Looker Studio** עם מפה חיה וסטטיסטיקות

## נספח: מעבר מ-POC ל-Production

כשה-POC יוכיח את עצמו, הנה הקפיצות הצפויות:

| רכיב | POC | Production |
|------|------|-------------|
| Database | Google Sheets | PostgreSQL + PostGIS |
| Backend | Apps Script | Node.js / Python (FastAPI) |
| Frontend | HTML סטטי / Form | React / Next.js |
| Real-time | Polling | WebSockets |
| Mobile | דף web | React Native |
| Hosting | GitHub Pages | AWS / GCP |

## נספח: ניתוח מתחרים – Workiz ו-Housecall Pro

שתי המערכות המובילות בתחום ה-Field Service Management (FSM) למפעלי שירות ותחזוקה.

### Workiz – פיצ'רים מרכזיים

**ניהול קריאות ותזמון:**
- לוח שנה ויזואלי צבעוני בסגנון drag & drop

- ניהול קבלני משנה
- ניהול מלאי

**אפליקציית טכנאי בשטח:**
- Clock-in/out למשמרת
- עדכון ETA אוטומטי ללקוח
- ניווט לכתובת
- הוספת הערות ותמונות
- הפקת חשבונית בשטח
- גביית תשלום במקום (כרטיס אשראי / ACH)

**תשלומים וחיובים:**
- Workiz Pay – מערכת תשלומים מובנית
- תזכורות אוטומטיות לתשלום
- מימון צרכני (תשלומים ללקוח)
- טיפים דיגיטליים
- סנכרון אוטומטי ל-QuickBooks Online

**AI ואוטומציה (חבילות מתקדמות):**
- **Genius Scheduling** – אופטימיזציה אוטומטית של תזמון
- **Genius Leads** – ניהול לידים מתקדם
- עשרות אוטומציות מובנות

**אינטגרציות:**
- Reserve with Google
- כלי SEO
- QuickBooks Online

**מודל תמחור:** Lite (חינם) → Kickstart → Standard → Pro → Ultimate

### Housecall Pro – פיצ'רים מרכזיים

**ניהול קריאות ותזמון:**

**הזמנה אונליין (יתרון משמעותי):**

**אפליקציית טכנאי:**

- Clock-in/out
- צ'אט עם הצוות

**תשלומים:**

- הפקדה ישירה לחשבון בנק

**שיווק ו-CRM:**
- אימיילים אוטומטיים
- גלויות בדואר פיזי
- בקשת ביקורות
- מעקב GPS אחר צוותים

### חסכים קריטיים שכדאי להוסיף לפני השקה
לפי סדר עדיפות:

**🔴 קריטי (חובה לפני השקה אמיתית):**
1. **SMS "אני בדרך"** – הציפייה הבסיסית של לקוח שירות ב-2026. אפשר לממש דרך Twilio/019 בעלות נמוכה
2. **מעקב סטטוס חי ללקוח** – דף web עם לינק ייחודי לכל קריאה
3. **חלונות הגעה** – לא להבטיח "ב-14:30" אלא "בין 14:00-16:00"
4. **התראות Push לטכנאי** – PWA או Telegram Bot כפתרון חינמי
5. **תיעוד תמונות בשטח** – חיוני להוכחת עבודה במוסכים
6. **חשבוניות ירוקות** – חובה חוקית בישראל מ-2024
